# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

React developers who use shadcn and want a complete terminal visual system without rebuilding common components themselves.

## Product purpose

Afterglow is a shadcn registry and documentation site. It installs a shared terminal theme, redrawn interface components, terminal-specific components, and composed blocks into a consumer's project.

## Positioning

Afterglow treats the terminal look as one installable system. The registry shares palette, typography, motion, CRT effects, and component behavior instead of shipping isolated themed snippets.

## Operating context

Developers evaluate Afterglow through the gallery and component reference, install it with the shadcn CLI, and use the installed source inside their own React application. Coding agents can read the same documentation through Markdown routes.

## Capabilities and constraints

- The registry is served from `public/r/` and published at `afterglow.thebuilder.dk`.
- Components use Base UI and shadcn registry conventions.
- The theme is dark and uses square corners, phosphor text, hairline borders, and stepped motion.
- Registry-generated component reference must remain consistent with source exports and examples.
- Authored guides must also appear in search and the agent-facing Markdown output.

## Brand commitments

The name is Afterglow. The incumbent terminal visual system and direct technical voice remain authoritative.

## Evidence on hand

The site has live component examples, complete installable source, installation commands, API documentation, a composed console, and machine-readable Markdown routes. No testimonials, customer logos, or usage metrics are available and none should be invented.

## Product principles

- Show working components and exact install commands.
- Keep authored guidance and generated reference distinct but connected.
- Let one theme govern every installed component.
- Give people and coding agents the same product facts.
